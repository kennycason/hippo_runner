# Hippo Runner + Cursor AI (~5 shot)

An infinite runner game featuring a cartoonish hippo character, built with Python and Pygame.

<img src="/screenshot01.png" width="50%" />

## Gameplay Video
Watch the gameplay video [here](hippo-runner.mp4).

## Features
- Infinite scrolling platformer
- Character movement and jumping mechanics
- Dynamic platform generation with varied heights and gaps
- Score tracking
- Pause functionality
- Game over conditions

## Controls
- Left/Right Arrow Keys or A/D: Move the hippo
- Space: Jump
- Enter: Pause/Resume game
- Space (on game over): Restart

## Requirements
- Python 3.x
- Pygame

## Installation
1. Clone the repository
2. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Game
```bash
python hippo_runner.py
```
